# TicTacToe

> A simple TicTacToe game, played in the console.

## About
The aim of this project is to familiarize myself with the basics of C++.
* **Standard:** C++20
* **Build System:** CMake 3.20+

## How to build
* It's recommended to create a separate build folder and run cmake from there.
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

### How to play
* Run the executable.
* Choose a game mode (singleplayer or multiplayer).
* Enjoy!
